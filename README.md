 HR Analytics Dashboard | Tableau

📊 Project Overview

An interactive **HR Analytics Dashboard built using Tableau** to analyze employee data and identify key workforce trends.

🎯 Objective

To provide meaningful insights into **employee attrition, demographics, job roles, departments, and workforce patterns** through interactive visualizations.

🛠️ Tools Used

* Tableau
* Data Visualization
* Data Analysis

📈 Key Insights

* Employee attrition trends
* Department-wise employee analysis
* Job role distribution
* Gender and demographic analysis
* Workforce trends

 💡 Outcome

The dashboard transforms HR data into clear and actionable insights, supporting **data-driven decision-making

Tableau | Data Analysis | Data Visualization | Dashboard Development | Business Intelligence
